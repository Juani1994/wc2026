# Core Requirement

The Round of 32 bracket is **partially dynamic**.

The dynamic part comes from the **8 qualified third-place teams**.

World Cup 2026 format:

```txt
12 group winners
12 runners-up
8 best third-place teams
=
32 teams
```

# Fixed Winner Slot Order

The mapping array MUST be interpreted using this exact order:

```ts
const WINNER_SLOTS = [
    "1A",
    "1B",
    "1D",
    "1E",
    "1G",
    "1I",
    "1K",
    "1L"
]
```

Meaning:

```txt
index 0 → opponent of 1A
index 1 → opponent of 1B
index 2 → opponent of 1D
index 3 → opponent of 1E
index 4 → opponent of 1G
index 5 → opponent of 1I
index 6 → opponent of 1K
index 7 → opponent of 1L
```

Example.

Combination:

```txt
BDEGHJKL
```

Lookup:

```ts
[
    "E",
    "J",
    "B",
    "D",
    "H",
    "G",
    "L",
    "K"
]
```

Expands to:

```txt
1A vs 3E
1B vs 3J
1D vs 3B
1E vs 3D
1G vs 3H
1I vs 3G
1K vs 3L
1L vs 3K
```

# Required Function

Create:

```txt
src/knockout.ts
```

Implement:

```ts
buildRoundOf32Bracket()
```

Responsibilities:

### 1

Read already existing standings state.

### 2

Extract:

* group winners
* group runners-up
* best thirds

### 3

Build third combination key.

Example:

Qualified thirds:

```txt
B D E G H J K L
```

Generate:

```txt
BDEGHJKL
```

Pseudo-code:

```ts
const comboKey =
    bestThirds
        .map(team => team.group)
        .sort()
        .join('')
```

### 4

Resolve official lookup.

```ts
const opponents =
    THIRD_PLACE_MAPPING[comboKey]
```

### 5

Generate dynamic winner matches.

Example:

```ts
const WINNER_SLOTS = [
    "1A",
    "1B",
    "1D",
    "1E",
    "1G",
    "1I",
    "1K",
    "1L"
]

const dynamicMatches =
    WINNER_SLOTS.map((slot,index)=>({

        home: slot,

        away:
            `3${opponents[index]}`
    }))
```

### 6

Build complete Round of 32 bracket.

Return:

```ts
type Match = {
    id:string
    home:Team
    away:Team
}
```
